# Sehar Tariq — Website 2 (No-scroll CV)

This version was built by reusing the **exact Website 1 source design**, including its original `styles.css`, colors, Manrope/DM Sans fonts, project previews and photo. The CV is divided into 11 full-screen panels without page scroll.

## Use
Open `index.html` locally. Navigate using footer buttons, section dropdown, keyboard arrows, or left/right swipes on a mobile device.

## Deploy to GitHub and Vercel
Create a *new* repository (`sehar-website2`) and upload all files in this folder (including `assets/`). In Vercel select **Import Git repository**, choose Framework Preset **Other**, leave build command blank and use root directory `./`. Then click Deploy.

No npm or external JavaScript packages required. Fonts use Google Fonts online.

## Content note
Project graphics are conceptual UI illustrations carried over from Website 1.
